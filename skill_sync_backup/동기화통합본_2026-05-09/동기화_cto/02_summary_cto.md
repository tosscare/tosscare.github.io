### ⑥ 계층 구조 (§8 — 3단계 깊이)

```
L1: 개발총괄 (동기화_cto) — 통합 메타 운용
 ├─ L2: 동기화_클로드
 │   └─ L3: (sub 프로젝트 — 단일)
 ├─ L2: 동기화_토스
 │   └─ L3: (sub 프로젝트 — 단일)
 ├─ L2: 동기화_외주
 │   ├─ L3: 동기화_외주1 / 외주2 / ...
 │   └─ L3: 동기화_인하우스1 / 인하우스2 / ...
 └─ L2: 동기화_콘텐츠
     └─ L3: (sub 프로젝트 — 단일)
```

| 룰 | 내용 |
|---|---|
| 깊이 제한 | 3단계 (L1 → L2 → L3) — 무한 깊이 ❌ |

| L3 sub 프로젝트 갯수 | 무한 (외주1·2·...·인하우스1·2·...) |
