# Project 지식 zip 다중 버전 보관 가이드

> **본 가이드는 §17 ⓦ-3 보강책 중 #2 (Project 지식 zip 다중 버전)의 mr.와이 영역 작업 가이드다.**
> 외부 백업 ❌ 환경에서 Anthropic Project 지식 슬롯을 다중화하여 데이터 소실 위험 ⬇️.
> 본 가이드는 mr.와이가 직접 수행하며, 클로드는 실행 ❌.

---

## 1. 개념

| 항목 | 내용 |
|---|---|
| 본질 | Project 지식 슬롯에 통합 zip을 **단일이 아닌 누적 버전**(v_n·v_n-1·v_n-2)으로 보관 |
| 효과 | 최신 zip 손상·일부 결함 발견 시 직전 v로 복구 가능 |
| 한계 | Project 지식 슬롯 용량 한도 내 (Anthropic 제공 한도 — mr.와이 환경 의존) |
| 책임 | mr.와이 (Anthropic 인프라 직접 조작 — 클로드 영역 ❌) |

---

## 2. 권장 보관 방식 (3중)

| 슬롯 | 파일명 (예시) | 용도 |
|---|---|---|
| **v_n (최신)** | `동기화통합본_2026-04-30.zip` | 현재 작업용 — 새 대화창 첫 진입 시 첨부 |
| **v_n-1 (직전)** | `동기화통합본_2026-04-29.zip` | 결함 발견 시 1차 복구 후보 |
| **v_n-2 (직-2)** | `동기화통합본_2026-04-28.zip` | 2차 복구 후보 (만일의 경우) |

> 3중 이상은 슬롯 용량 부담 ⬆️. **3중 권장**.

---

## 3. 갱신 절차 (매 ⓥ-2 새 대화창 이전 시점)

### Step 1 — 클로드(L1)에서 새 통합본 받기

| 동작 | 결과물 |
|---|---|
| 클로드가 ⓥ-2 발동 → 3종 산출물 생성 | (1) `instruction_cto.md` (zip 밖) / (2) `동기화통합본_YYYY-MM-DD.zip` / (3) `통합업무파일.html` (zip 밖) |

### Step 2 — Project 지식 슬롯 갱신

| 슬롯 | 직전 | 갱신 후 |
|---|---|---|
| 최신 | v_n | v_n+1 (새 zip) |
| 직전 | v_n-1 | v_n (← 직전 v_n이 직전으로 이동) |
| 직-2 | v_n-2 | v_n-1 |
| (직-3) | v_n-3 | **❌ 삭제** |

→ **회전 보관**. 매 갱신 시 가장 오래된 v 1개 삭제, 새 v 1개 추가.

### Step 3 — 인스트럭션 슬롯 갱신

`instruction_cto.md`는 zip 밖 별도 파일 (ⓜ 룰). 슬롯에 단일 박제 — 다중 버전 ❌. 가장 최신만 박제.

---

## 4. 결함 발견·복구 시나리오

### 시나리오 A — 새 대화창 진입 시 ⓨ 정합 검증 불일치 발견

| 단계 | 동작 |
|---|---|
| 1 | L1이 정합 검증 실패 정직 보고 |
| 2 | L1이 ㉠ conversation_search 사후 복구 시도 |
| 3 | 그래도 부족 시 — mr.와이가 **v_n-1** 첨부로 복구 |

### 시나리오 B — 최신 zip 손상·결함 다수 발견

| 단계 | 동작 |
|---|---|
| 1 | mr.와이가 새 대화창 시작 시 **v_n-1** 첨부 (v_n 폐기) |
| 2 | L1이 v_n-1 기준으로 작업 이어감 |
| 3 | L1이 v_n에서 누락된 합의·박제 정합 자체 보강 |

### 시나리오 C — 컨테이너 리셋 빈발

| 단계 | 동작 |
|---|---|
| 1 | 본 대화창에서 컨테이너 리셋 발생 시 |
| 2 | L1이 zip 재해제 + 작업 재진행 (현재 운용 중인 방식) |
| 3 | 본 가이드는 새 대화창 단위 보장이지 본 대화창 내 컨테이너 리셋 보장 ❌ |

## 5. mr.와이 영역 vs 클로드 영역 구분

| 영역 | 책임 |
|---|---|
| **mr.와이** | Project 지식 슬롯 직접 조작 / zip 파일 보관·이름 부여·삭제 / 인스트럭션 슬롯 갱신 |
| **클로드 (L1)** | 새 통합 zip 생성 (ⓥ-2 시점) / 다중 버전 자체 관리 ❌ |

> 본 가이드에 따른 슬롯 갱신은 **mr.와이 직접 수행** — 클로드가 자동으로 회전 ❌.
